# CLP Hero Compound Report

Date: 2026-08-03
Branch: `codex/clp-hero`

## Request

Implement the CLP intro hero from the desktop and mobile Figma references, show it on the collection page, run compound review, and provide a full report.

## Figma Reference

- Desktop node: `2:4419`
- Mobile node: `13:4518`
- Heading: `All Products`, Chronicle Display Light, 40px desktop and 28px mobile, 1.1 line-height, tight tracking
- Body: Helvetica Neue Light, 16px, 1.5 line-height
- Layout: left-aligned stack with an 8px gap, placed above the collection controls/product grid

## Implementation

Created `sections/clp-intro.liquid`.

The section renders:

- `collection.title` as the default heading
- `collection.description` as the default body copy
- optional merchant heading and description overrides
- optional fallback body copy, restricted by collection handle
- scoped Ogee typography so global Horizon typography settings are not changed
- desktop and mobile padding/gutter controls

Updated `templates/collection.json`.

The collection template now renders `clp-intro` before `main-collection`, replacing the generic Horizon text-block heading. The existing filter block, product grid settings, product card block, and collection pagination remain untouched.

## Review Findings

No outstanding actionable issues remain.

One issue was found and fixed during review:

- Severity: medium
- Issue: a lorem fallback description in the default collection template could appear on any collection with an empty description
- Fix: added `description_fallback_collection_handle` and set it to `all` in `templates/collection.json`
- Result: the Figma placeholder fallback only appears on the `all` collection unless a merchant intentionally clears or changes the handle setting

## Verification

Passed:

- Shopify Liquid validator for `sections/clp-intro.liquid`
- Shopify Liquid validator for `templates/collection.json`
- `templates/collection.json` body parse after removing Shopify's generated banner comment
- `sections/clp-intro.liquid` schema JSON parse
- trailing whitespace check for edited files

Notes:

- The repo-local validator copy is missing `@shopify/theme-check-common`, so validation was run through the bundled Shopify plugin runtime with cached theme schemas.
- Shopify CLI is not available in this workspace, and no store preview config was present, so live browser preview could not be started locally.

## Residual Risks

- Exact Chronicle Display and Helvetica Neue fidelity depends on the storefront loading those licensed fonts.
- Pixel verification still needs a Shopify preview URL because Liquid collection data and Shopify theme wrappers are not fully renderable from static files alone.
- `templates/collection.json` is generated by the Shopify theme editor, so future theme-editor saves can modify this wiring.

## Compound Summary

The CLP hero is now a dedicated Shopify section on the collection page. The implementation keeps Figma-specific typography scoped to the section, preserves dynamic collection title and description behavior, and avoids leaking placeholder text to unrelated collection pages. Validation passed, and review found no remaining actionable issues.
